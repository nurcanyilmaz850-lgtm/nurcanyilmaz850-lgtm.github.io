Nurcan Yılmaz Personal Website
================================

Bu site, HTML5 UP üzerindeki Prologue şablonunun tek sayfalı kişisel portföy yaklaşımı seçilerek hazırlanmıştır.
HTML5 UP Prologue: https://html5up.net/prologue

GitHub Pages:
1. GitHub'da yeni bir repository oluşturun (ör. nurcanyilmaz850-lgtm.github.io).
2. Bu ZIP içindeki tüm dosyaları repository'nin kök dizinine yükleyin.
3. Settings > Pages > Deploy from a branch seçin.
4. Branch: main, Folder: / (root) seçin.
5. Save.

Fotoğraf:
assets/profile.png dosyasını başka bir fotoğrafla aynı adla değiştirerek fotoğrafı kolayca güncelleyebilirsiniz.

CV:
Şimdilik Word CV eklenmiştir. Overleaf'ten PDF CV'nizi indirdiğinizde cv klasörüne ekleyip bağlantıyı PDF'ye çevirebiliriz.
